# Tula Clients Bot

Telegram-бот для поиска клиентов малого бизнеса в Туле через 2ГИС с автогенерацией холодных сообщений и промптов для разработки через OpenRouter.

## Что умеет

- Парсит 2ГИС по городу Тула
- Ищет в категориях: салоны красоты, стоматологии, кафе, фитнес, автосервисы, репетиторы
- Фильтрует сетевой бизнес (Spar, Лента, Магнит, KFC, банки, операторы и т.п.)
- Показывает: название, адрес, телефон, сайт, VK, Telegram
- Генерирует под каждый бизнес:
  - 💬 холодное сообщение для VK
  - ✈️ холодное сообщение для Telegram
  - 📞 скрипт холодного звонка
  - 🤖 промпт для разработки Telegram-бота
  - 🌐 промпт для разработки сайта-визитки

Интерфейс — только кнопки. Команды вводить не нужно.

## Стек

- Python 3.11
- aiogram 3.x
- httpx
- openai (через OpenRouter)
- python-dotenv

## Структура

```
main.py            # точка входа

requirements.txt
.env.example
```

## Подготовка ключей

### 1. BOT_TOKEN — токен Telegram-бота

1. Открой в Telegram [@BotFather](https://t.me/BotFather)
2. `/newbot` → задай имя и username
3. Получишь токен вида `123456:ABC-DEF…` — это `BOT_TOKEN`

### 2. TWOGIS_API_KEY — ключ 2ГИС

1. Зайди на <https://dev.2gis.ru/>
2. Зарегистрируйся и зайди в личный кабинет
3. Создай ключ для **Places API** (`catalog.api.2gis.com`) — у 2ГИС есть бесплатный лимит
4. Скопируй ключ — это `TWOGIS_API_KEY`

### 3. OPENROUTER_API_KEY — ключ OpenRouter

1. Заходи на <https://openrouter.ai/>
2. Зарегистрируйся
3. В разделе **Keys** создай новый ключ
4. Пополни баланс (модель `deepseek/deepseek-chat` стоит копейки) или используй бесплатные модели
5. Скопируй ключ — это `OPENROUTER_API_KEY`

## Локальный запуск

```bash
git clone <repo>
cd <repo>
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# открой .env и впиши свои ключи
python main.py
```

После запуска открой бота в Telegram и нажми `/start`.

## Деплой на Railway

1. Залей репозиторий на GitHub.
2. Зарегистрируйся на <https://railway.app/>.
3. **New Project → Deploy from GitHub repo → выбери репозиторий.**
4. После создания проекта открой вкладку **Variables** и добавь три переменные:
   - `BOT_TOKEN`
   - `TWOGIS_API_KEY`
   - `OPENROUTER_API_KEY`
5. Во вкладке **Settings → Deploy** проверь, что Start Command = `python main.py` (можно не трогать, Procfile уже есть).
6. Railway сам поставит зависимости из `requirements.txt` и запустит `worker`.
7. После деплоя зайди в логи — должна быть строка `Бот стартует…`.
8. Открой бота в Telegram, нажми `/start` — готово.

## Использование

1. `/start` → внизу появится постоянная клавиатура.
2. **🔍 Найти клиентов** → выбираешь категорию из сетки 2×4.
3. Бот покажет до 30 бизнесов с пагинацией по 5 (кнопка «Ещё 5 →»).
4. Тапаешь по бизнесу → получаешь карточку и 5 действий: VK, Telegram, звонок, промпт бота, промпт сайта.
5. Текст под 4096 символов разбивается на несколько сообщений автоматически.

## Заметки

- Если 2ГИС не отвечает — бот предложит кнопку «🔄 Попробовать снова».
- Все состояния пользователя хранятся в `MemoryStorage` (на время работы процесса).
- Категории и чёрный список сетевых брендов лежат в `config.py` — расширяй под себя.
